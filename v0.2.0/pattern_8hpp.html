Detailed Description

File patterns for choosing what to download (--include "*.safetensors"), as huggingface_hub matches them.

Overview

huggingface_hub's allow_patterns / ignore_patterns are Python fnmatch patterns over the file's path in the repository: * matches any run of characters, / included; ? one character; [abc], [a-z] and [!abc] a set; and a pattern ending in / matches everything under that directory. matches implements exactly that, and select applies include and exclude lists (no include list means everything).

Relationships
See also
formats::hub::client::download
Implementations and variants

A backtracking matcher, linear in practice for these patterns.

Guarantees and contracts

constexpr, noexcept, no allocation.

Errors

None: an unclosed [ matches a literal [, as fnmatch does.

Examples
const std::vector<std::string> include{"*.json", "*.safetensors"};
const std::vector<std::string> exclude{"onnx/"};
Performance

Not benchmarked: a few patterns over a few files.

Tests and demos

tests/hub/pattern_test.cpp (fnmatch's cases), demos/hub/pattern_demo.cpp.

Dependencies

The standard library.

Known issues and gotchas

Matching is case-sensitive (fnmatch's is on POSIX).

Status

Experimental.
