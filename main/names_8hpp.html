Detailed Description

Checkpoint tensor names: Hugging Face's and llama.cpp's to one tensor_name (a role, a layer, an expert) and back, and the RoPE permutation llama.cpp's converter applies to Q and K.

Overview

The same weight is model.layers.3.self_attn.q_proj.weight in a Hugging Face Llama, h.3.attn.c_attn.weight (Q, K and V fused) in GPT-2, and blk.3.attn_q.weight in GGUF. parse_hf_name and parse_gguf_name turn a name into a tensor_name, a role (core's parts of a block: q, k, v, o, gate, up, down, the norms, the embeddings, the head, the router, the experts, latent attention's projections) with its layer and expert; hf_name and gguf_name turn it back. A name no rule matches is none, never guessed.

Two layout facts go with the names:

  • GPT-2's Hugging Face checkpoints store the projections as Conv1D, [in, out]; every other format (llm.c, GGUF, PyTorch Linear, core) stores [out, in]. hf_transposed says which: transpose those when converting.
  • llama.cpp stores Llama's Q and K for adjacent-pair RoPE: its converter permutes the rows of each head from halves to pairs (LlamaModel.permute: reshape to [heads, 2, head_dim / 2, ...], swap axes 1 and 2). permute_rope applies it and unpermute_rope undoes it, over rows of any type (quantised rows included). The Qwen and OLMoE architectures are not permuted (llama.cpp runs them with NeoX RoPE).

GGUF stacks a layer's experts into one tensor (blk.N.ffn_up_exps.weight, [experts, out, in]); Hugging Face keeps one per expert. gguf_name of an expert's weight is the stacked tensor's name, and conversion stacks them.

Guarantees and contracts

parse_hf_name(a, hf_name(a, n)) == n for every name hf_name gives; the same for GGUF. unpermute_rope(permute_rope(x)) == x.

Errors

None: an unknown name is std::nullopt; permute_rope asserts its sizes.

Examples
const auto q = parse_hf_name(architecture::llama, "model.layers.3.self_attn.q_proj.weight");
const std::string in_gguf = gguf_name(*q); // "blk.3.attn_q.weight"
const bool permute = gguf_permutes(architecture::llama, *q); // true: RoPE pairs
const auto fused = parse_hf_name(architecture::gpt2, "h.0.attn.c_attn.weight"); // Conv1D, [in, out]
Performance

Not benchmarked: a few string comparisons per tensor; the permutation is one copy.

Tests and demos

tests/hf/names_test.cpp (the permutation against numpy's reshape and swapaxes, by hand), demos/hf/names_demo.cpp.

Dependencies

The standard library.

Known issues and gotchas

GPT-2's attn.bias and attn.masked_bias are causal-mask buffers, not weights: role::mask_buffer, which conversion drops.

Status

Experimental.
