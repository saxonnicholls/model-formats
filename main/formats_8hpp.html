Detailed Description

The umbrella: every model-formats header that needs nothing but the standard library and core.

Overview

One include for the readers and writers that need no third party (GGUF, .npy, llm.c, PyTorch checkpoints, zip, and the shared vocabulary types), sorted, and the source of the single include snicholls_formats.hpp (tooling's single_include.py), which is this with every model-formats and snicholls-core header it uses expanded in one file, generated and never committed. The headers that parse JSON (nlohmann/json through core-adapters) or link OpenSSL are left out (single_include_opt_in in tooling.conf, each with its reason) and are included one by one, through snicholls::formats_io and snicholls::formats_hub.
