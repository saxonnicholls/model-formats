Detailed Description

model_config: a checkpoint's architecture as core's ml::transformer_config plus the sizes around it.

Overview

Hugging Face's config.json and GGUF's metadata describe a model in two vocabularies; core describes a block in one, ml::transformer_config. A model_config is the meeting point: the block, the counts a block does not hold (layers, vocabulary, context, the dense layers before the mixture-of-experts ones), the embedding tie and the special tokens, and notes, one line for every field of the source that does not map onto core (a RoPE scaling core lacks, a bias core places differently). hf::parse_config and gguf::read_model_config fill it; gguf::write_model_config writes it back as GGUF keys.

The values are run-time values: core's transformer_config is a literal type, so a configuration known at compile time can still be checked against one read from a file (same_block(c.block, ml::llama3_8b)).

Relationships
See also
snicholls::ml::transformer_config (core), formats::hf::parse_config, formats::gguf::read_model_config
Implementations and variants

One struct and an enumeration of the architectures mapped: GPT-2, Llama, Mistral, Qwen 2, Qwen 3, OLMoE, DeepSeek-V2 and DeepSeek-V3.

Guarantees and contracts

A model_config returned by a reader satisfies ml::valid(block).

Errors

None of its own.

Examples
model_config c;
c.arch = architecture::llama;
c.block = snicholls::ml::llama3_8b; // core's preset
c.layers = 32;
c.vocab = 128256;
c.context = 8192;
Performance

Not benchmarked: plain data.

Tests and demos

tests/model_config_test.cpp, demos/model_config_demo.cpp.

Dependencies

Core's ml/transformer_config.hpp.

Known issues and gotchas

GGUF stores Llama's Q and K permuted for adjacent-pair RoPE, so the same model reads as rope_kind::half from Hugging Face and rope_kind::interleaved from GGUF; hf::permute_rope converts the weights.

Status

Experimental.

olmoe 

OLMoE: a softmax-routed mixture of experts.

deepseek_v2 

DeepSeek-V2: latent attention, softmax-routed experts.

deepseek_v3 

DeepSeek-V3: latent attention, sigmoid-routed grouped experts, multi-token prediction.
