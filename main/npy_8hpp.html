Detailed Description

NumPy's .npy (versions 1 to 3) and .npz (a zip of .npy members): read and write.

Overview

An .npy file is the magic \x93NUMPY, a version, a header length, then a Python dict literal, {'descr': '<f4', 'fortran_order': False, 'shape': (2, 3), }, padded with spaces and a newline so the data starts at a multiple of 64. parse_npy reads the dict with a small parser that accepts exactly that shape (it never evaluates Python) and returns a tensor_view into the bytes. write_npy writes what np.save writes, byte for byte (version 1.0, or 2.0 when the header is over 64 KiB, with numpy's spare space after the dict). parse_npz / write_npz do the same for np.savez archives: one stored <name>.npy per array.

Element types: <f8 <f4 <f2 <i8 <i4 <i2 |i1 <u8 <u4 <u2 |u1 |b1 (and = for native, which is little-endian here). NumPy has no bfloat16 or eight-bit floats: writing those is bad_dtype.

Relationships
See also
formats::zip, formats::tensor_view
Implementations and variants

One header parser; npz through zip.

Guarantees and contracts

The view borrows the bytes. A Fortran-ordered, big-endian or structured array is refused, never misread.

Errors

truncated, bad_magic, unsupported_version, bad_header (the dict is malformed), bad_dtype, bad_shape, unsupported (Fortran order, big-endian); npz adds zip's errors (savez_compressed is unsupported).

Examples
const std::vector<float> embedding(4 * 8, 0.125f);
const std::vector<std::int64_t> ids{5, 7, 11};
const std::vector<tensor_view> arrays{{"embedding", dtype::f32, {4, 8}, std::as_bytes(std::span(embedding))},
{"ids", dtype::i64, {3}, std::as_bytes(std::span(ids))}};
const auto npz = np::write_npz(arrays); // np.load reads it
const auto back = np::parse_npz(*npz); // views into `npz`
Performance

Not benchmarked: a header per array.

Tests and demos

tests/numpy/npy_test.cpp (and numpy itself in scripts/crosscheck.sh), demos/numpy/npy_demo.cpp.

Dependencies

The standard library and core.

Known issues and gotchas

A 0-dimensional array's shape is (); a 1-dimensional one's (n,), with the comma.

Status

Experimental.
