Detailed Description

The Hugging Face cache, laid out as huggingface_hub lays it out, so either can use the other's downloads.

Overview
<cache>/models--<org>--<name>/
blobs/<etag> the file, named by its SHA-256 (LFS) or git blob id
blobs/<etag>.incomplete a download in progress (resumed from where it stopped)
snapshots/<commit>/<path> a relative symlink to ../../blobs/<etag> (deeper for deeper paths)
refs/<revision> the commit a branch or tag resolved to

default_cache_dir follows huggingface_hub: HF_HUB_CACHE, else HF_HOME/hub, else XDG_CACHE_HOME/huggingface/hub, else ~/.cache/huggingface/hub, read through ts-moveables' configuration (never getenv here). cache computes the paths, records refs, links snapshots, and resolves a revision offline.

Relationships
See also
formats::hub::client
Implementations and variants

Paths and small files; nothing is held open.

Guarantees and contracts

Repository ids are checked (org/name or name, characters [A-Za-z0-9._-], no ..) and file paths with safe_relative_name, so nothing from the server can name a path outside the cache.

Errors

bad_argument (an unsafe repository id, revision or path), Files, offline (a revision never resolved).

Examples
const auto c = cache::open(default_cache_dir(), "hf-internal-testing/tiny-random-gpt2");
const auto blob = c->blob("e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855");
const auto snap = c->snapshot("0123456789abcdef0123456789abcdef01234567");
Performance

Not benchmarked: a few system calls.

Tests and demos

tests/hub/cache_test.cpp, demos/hub/cache_demo.cpp.

Dependencies

ts-moveables (process/config.hpp, fs/file.hpp).

Known issues and gotchas

Symlinks need a filesystem that has them; on one that does not (some network shares) linking fails with Files.

Status

Experimental.
