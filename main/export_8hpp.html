Detailed Description

Model-level conversion: our llm.c checkpoints to Hugging Face safetensors and to GGUF, and Hugging Face checkpoints to GGUF and back, with the names, layouts and metadata each side expects.

Overview
  • llmc_to_hf turns an llm.c GPT-2 checkpoint into Hugging Face's GPT-2 tensors (wte.weight, h.N.attn.c_attn.*, ...): Q/K/V/O and the MLP transposed to Conv1D's [in, out], the token table cut to the real vocabulary, the head left tied; hf_gpt2_config writes the matching config.json.
  • llmc_to_gguf writes the same model as llama.cpp's gpt2 architecture, every tensor a view into the checkpoint (llm.c's [out, in] layout is ggml's), with the metadata llama.cpp needs to load it, including the tokenizer.
  • hf_to_gguf converts a Hugging Face checkpoint of GPT-2, Llama, Mistral, Qwen 2, Qwen 3 or OLMoE: names through hf::gguf_name, GPT-2's transposes, llama.cpp's Q/K permutation for Llama and Mistral, routed experts stacked into one tensor per layer, the tied head dropped; gguf_to_hf is the inverse (names, unpermuted, unstacked).

Tensors that need no change are views; the rest are copies held in the result's owned (a deque, so the writer's views of them stay valid).

Implementations and variants

One function per direction.

Guarantees and contracts

gguf_to_hf(parse(hf_to_gguf(t))) gives back t's tensors bit for bit (a test proves it for every architecture supported). The GGUF written by llmc_to_gguf is read by gguf-py (scripts/crosscheck.sh).

Errors

unsupported (DeepSeek's latent attention, which llama.cpp splits differently; a tensor no rule names), bad_shape (a tensor whose shape does not match the configuration), not_found (a tensor the architecture needs).

Examples
const auto ckpt = llmc::parse_checkpoint(*file);
const auto hf = llmc_to_hf(*ckpt); // wte.weight, h.0.attn.c_attn.weight, ...
const auto st = safetensors::write(hf->tensors, {{{"format", "pt"}}});
const std::string config = hf_gpt2_config(s); // config.json beside it
const auto gg = llmc_to_gguf(*ckpt, &v, "tiny-gpt2"); // llama.cpp's gpt2, tensors viewed in place
const auto gguf_bytes = gg->writer.write();
Performance

Not benchmarked: one copy of each transposed, permuted or stacked tensor; views for the rest.

Tests and demos

tests/convert/export_test.cpp, demos/convert/export_demo.cpp.

Dependencies

The format headers here.

Known issues and gotchas

llama.cpp refuses an unknown tokenizer.ggml.pre: an empty vocabulary::pre is written as "gpt-2" for GPT-2 and "default" otherwise.
