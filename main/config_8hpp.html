Detailed Description

Hugging Face's config.json to a model_config, and generation_config.json.

Overview

parse_config reads a transformers config.json for GPT-2, Llama, Mistral, Qwen 2, Qwen 3, OLMoE, DeepSeek-V2 and DeepSeek-V3 into core's transformer_config and the counts around it, using transformers' defaults where a field is absent. What does not map is kept in notes, never dropped silently:

Field Where it goes
rope_scaling linear / YaRN rope_scaling, rope_factor, YaRN's context, betas and mscale (YaRN as Hugging Face computes it: yarn_index_ramp)
rope_scaling llama3, dynamic, longrope a note: core has no such rescaling
Qwen 2's Q/K/V biases bias = true, with a note that the O and MLP biases are zero
OLMoE's q_norm / k_norm a note: OLMoE normalises the whole projection, core's qk_norm is per head
norm_topk_prob with softmax routing softmax_top_k when true, softmax when false
DeepSeek's first_k_dense_replace leading_dense_layers; the dense blocks' width is d_ff
DeepSeek-V3's bias update rate a note: the configuration does not carry it
hidden_act other than silu (gated) / gelu_new / gelu an error: core has no such MLP

parse_generation_config reads the sampling defaults a model ships with.

Relationships
See also
formats::model_config, formats::hf::checkpoint_names, formats::gguf::write_model_config
Implementations and variants

One parser per architecture family, sharing the attention and RoPE fields.

Guarantees and contracts

A configuration returned satisfies ml::valid(c.block).

Errors

bad_json; bad_header for a missing required field or a configuration core rejects; unsupported for a model_type or activation not mapped.

Examples
const auto c = hf::parse_config(R"({"model_type":"llama","hidden_size":4096,"num_attention_heads":32,
"num_key_value_heads":8,"num_hidden_layers":32,"intermediate_size":14336,"rms_norm_eps":1e-05,
"rope_theta":500000.0,"vocab_size":128256,"max_position_embeddings":8192,"hidden_act":"silu",
"rope_scaling":{"rope_type":"llama3","factor":8.0}})");
const bool same_block_as_core = same_block(c->block, snicholls::ml::llama3_8b);
for (const auto& note : c->notes)
std::printf("not mapped: %s\n", note.c_str());
Performance

Not benchmarked: read once per model.

Tests and demos

tests/hf/config_test.cpp (the configurations of GPT-2, Llama 3 8B, Qwen 3, OLMoE and DeepSeek-V3 against core's presets), demos/hf/config_demo.cpp.

Dependencies

nlohmann/json through core-adapters.

Known issues and gotchas

Hugging Face Llama applies RoPE to the halves of a head (rotate_half): rope_kind::half.

Status

Experimental.
