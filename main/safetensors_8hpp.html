Detailed Description

safetensors: read (validated, zero-copy) and write (aligned, deterministic).

Overview

A safetensors file is an 8-byte little-endian header length N, N bytes of JSON, then the data. The JSON maps each tensor name to {"dtype", "shape", "data_offsets": [begin, end]} (offsets into the data, which follows the header) and may hold "__metadata__", a map of strings to strings. parse reads the header and returns views into the bytes it was given: nothing is copied, so parsing a mapped 10 GB file costs the header alone.

Validation is the reference implementation's and stricter: the header starts with { and is at most 100 MB; every key appears once; every dtype is known; every extent product and byte count is computed without overflow and equals end - begin; every range lies inside the data; ranges do not overlap; and, unless allow_holes, they cover the data exactly, as the reference requires.

write sorts the tensors by element size (largest first) and then by name, so every tensor starts at a multiple of its element size, pads the header with spaces to a multiple of 8, and emits the JSON with sorted keys: the same tensors always give the same bytes.

Relationships
See also
formats::tensor_view, formats::safetensors::index (sharded checkpoints), formats::io::open_model
Implementations and variants

parse and write over bytes; write_to over any byte sink, so a caller can stream to a file.

Guarantees and contracts

parse never reads outside its span and never throws for malformed input; the returned file borrows the bytes for its tensors' data. write produces a file parse accepts.

Errors

truncated, too_large (header over the limit), bad_header, bad_json, duplicate_name, bad_dtype, bad_shape, out_of_bounds, overlap (including holes). Writing: duplicate_name, bad_shape (data size does not match), bad_argument (a name that is not valid UTF-8, or __metadata__).

Examples
const std::vector<float> w{1, 2, 3, 4, 5, 6};
const std::vector<float> b{0.5f, -0.5f};
const std::vector<tensor_view> tensors{{"proj.weight", dtype::f32, {2, 3}, std::as_bytes(std::span(w))},
{"proj.bias", dtype::f32, {2}, std::as_bytes(std::span(b))}};
const std::vector<st::metadata_entry> meta{{"format", "pt"}};
const auto bytes = st::write(tensors, meta); // sorted, aligned, deterministic
const auto file = st::parse(*bytes); // views into `bytes`, nothing copied
for (const auto& t : file->tensors)
std::printf("%-12s %s %s at [%llu, %llu)\n", t.name.c_str(), safetensors_name(t.type).data(), to_string(t.shape).c_str(),
static_cast<unsigned long long>(t.begin), static_cast<unsigned long long>(t.end));

Known issues and gotchas
