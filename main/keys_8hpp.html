Detailed Description

GGUF's standard metadata keys (general.*, <arch>.*, tokenizer.ggml.*) and their enumerations.

Overview

The key names llama.cpp reads, from gguf-py's constants.py (llama.cpp, MIT), so a key is spelt once. general::* and tokenizer::* are whole keys; the per-architecture keys are suffixes, joined to the architecture by arch_key("llama", llm::context_length) = "llama.context_length". token_type is tokenizer.ggml.token_type's values and file_type the general.file_type codes used here.
