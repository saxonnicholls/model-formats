Detailed Description

The version of model-formats, as macros and as values.

Overview

The library's version, written in three places (here, project(... VERSION) in CMakeLists.txt, and the release tag), which scripts/check_version.py keeps equal. SNICHOLLS_FORMATS_REQUIRE_VERSION is the compile-time check a consumer's header makes.

Relationships

The counterpart of core's version.hpp; snicholls::formats::version holds the values.

Implementations and variants

Macros for the preprocessor, constexpr values for C++.

Guarantees and contracts

Compile time only; no state.

Errors

SNICHOLLS_FORMATS_REQUIRE_VERSION fails to compile when the library is older than asked.

Examples
SNICHOLLS_FORMATS_REQUIRE_VERSION(0, 1, 0); // fails to compile on an older model-formats
std::printf("model-formats %s\n", snicholls::formats::version::string);
Performance

Not benchmarked: compile time only.
