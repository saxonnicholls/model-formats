Detailed Description

Any format to any: detect a file's format, read its tensors, write them in another, cast and dequantise.

Overview

detect names a file's format from its first bytes (safetensors' length-prefixed {, GGUF, \x93NUMPY, a zip holding .npy members or a data.pkl, llm.c's magics); read_any reads any of them into one loaded set of tensors and string metadata, as views where the bytes allow it and as owned copies where they do not (GGUF's quantised tensors dequantised to F32 through core, PyTorch's non-contiguous tensors made row-major). write_any writes a set of tensors as safetensors, GGUF, .npz or .npy. cast changes a tensor's dtype; dequantize turns a GGUF tensor of a type core has (Q8_0, Q4_0, MXFP4) into F32.

This is the tensor-level conversion: names and layouts are kept as they are. Model-level conversion (Hugging Face names to llama.cpp's, the RoPE permutation, GPT-2's transposes, stacked experts) is convert::export.hpp's.

Relationships
See also
formats::convert::hf_to_gguf, formats::io::open_model (from a path)
Implementations and variants

One reader per format behind read_any; one writer per format behind write_any.

Guarantees and contracts

A loaded borrows the bytes it was read from for its views and owns its copies; moving it keeps every view valid.

Errors

The format readers' errors; unsupported for an unknown format, a GGUF quantisation core does not have, or a target that cannot hold a dtype (NumPy and bfloat16, GGUF and unsigned integers: cast first).

Examples
const auto st = write_any(file_format::safetensors, tensors);
const auto from_st = read_any(*st); // detects safetensors
const auto gg = write_any(file_format::gguf, from_st->tensors); // the same tensors as GGUF
const auto from_gg = read_any(*gg);
const auto npz = write_any(file_format::npz, from_gg->tensors); // and as np.savez
const auto bf16 = cast(from_gg->tensors[0], dtype::bf16); // half the bytes
Performance

Views cost nothing; casts and dequantisation are one pass per element.

Tests and demos

tests/convert/convert_test.cpp (round trips between every pair of formats), demos/convert/convert_demo.cpp.

Dependencies

Every format header here; core's ml/quantize.hpp.

Known issues and gotchas

GGUF metadata becomes key = value text in loaded::metadata (arrays summarised by their length), so a GGUF to GGUF round trip through write_any keeps strings and numbers as strings: use gguf::writer to keep types.

Status

Experimental.
